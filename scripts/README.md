# Ferramentas de manutenção

`node scripts/gerar-miniaturas.mjs` atualiza as duas miniaturas da Pracinha em dist/arte. O script chama draw(ctx) das fábricas com um contexto que registra retângulos e produz SVGs. Não requer dependências externas. Execute novamente após mudar sprites ou paletas de pracinha.js.
