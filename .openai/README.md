# Manifesto da hospedagem

[hosting.json](hosting.json) vincula a instalação de referência ao projeto de hospedagem e define `dist` como diretório estático. O campo `project_id` identifica essa instalação. O campo `static.directory` indica ao publicador onde encontrar o HTML e os recursos.

Para uma execução local, sirva [dist/](../dist/README.md) diretamente. Uma instalação independente usa a configuração própria de seu provedor. As permissões de acesso ao endereço hospedado são administradas no serviço.
