# Telas reais do Miudezas

## Origem

Capturadas em **18 de novembro de 2026**, navegando pela versão pública em [GitHub Pages](https://luigiscofano.github.io/Miudezas/), em navegador Chromium de computador. Foram usados os controles reais da aplicação; não são simulações, montagens ou imagens geradas.

Cada JPEG contém a janela completa da aplicação: título, conteúdo, controles e rodapé. O recorte remove somente a margem vazia externa do navegador. O ponteiro foi mantido fora da região capturada. As imagens preservam a apresentação efetivamente exibida, sem retoques.

## Como atualizar

1. Abra a versão publicada após conferir que a alteração desejada está disponível.
2. Navegue pelos menus reais até cada estado documentado.
3. Mantenha a janela inteira, incluindo bordas e rodapé, e mova o cursor para fora da área capturada.
4. Capture a região da aplicação sem alterar seus elementos. Confira visualmente cada arquivo antes de substituir.
5. Atualize esta data e as legendas junto com as imagens no mesmo PR.

Estas capturas documentam a interface de **computador**, não uma verificação em celular físico. Para imagens isoladas de todos os tabuleiros, consulte [cenas atuais dos jogos](../jogos/README.md); o método de geração e a finalidade são diferentes.
